STAR reader
===========

The STAR format is a DASL container: a DAG-CBOR map of metadata followed by pairs of key and value. The ``$type`` of the metadata names the profile that defines what the keys and the values mean. The repo of an account in a space is exported as a STAR file.

Specification: https://dasl.ing/star.html
